# Teka

Папки на робочому столі Windows, як на телефоні: скляна іконка з мініатюрами 3×3, яка по кліку розкривається в напівпрозору панель з програмами.

## Як користуватись

- **Додати програму** — перетягни ярлик, exe, файл чи теку на папку або у відкриту панель. Або натисни «+ Додати» в панелі.
- **Відкрити папку** — клік по іконці. Закрити — клік поза панеллю або Esc.
- **Перемістити папку** — потягни іконку мишею.
- **Перейменувати** — клікни на назву у відкритій панелі або права кнопка → «Перейменувати».
- **Порядок іконок** — перетягуй іконки всередині панелі. Іконку можна перетягнути на іншу папку.
- **Прибрати з папки** — права кнопка на іконці.
- **Трей** — нова папка, сховати/показати всі папки, автозапуск, перенесення ярликів з робочого столу.

Ярлики копіюються у `%AppData%\Teka\Shortcuts`, тож папка не зламається, якщо прибрати ярлик з робочого столу. Налаштування — `%AppData%\Teka\config.json`.

## Встановлення і оновлення

Завантаж `Teka-win-Setup.exe` з [Releases](https://github.com/dimasdonetsk/teka/releases/latest) і запусти. Teka встановиться в `%LocalAppData%\Teka` і сама підтягуватиме нові версії (перевіряє раз на 6 годин, або вручну: трей → «Перевірити оновлення»).

GitHub Actions на кожен пуш у `main` збирає програму, пакує її через Velopack і публікує реліз.
